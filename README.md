# Item-Shop-Journey
In this repository, I document my CS40 (intro to C++) class project. Each student was given a choice to create a project about anything, but it just had to include what we had learned since the start of the class, so classes, object-oriented learning, functions, etc.

I thought of doing something entertaining, as I would enjoy making the project if it were something unique instead of something ordinary, so I chose the game Fortnite to match that goal. Specifically, what about Fortnite did I want to code about? I remember in high school (2018-2019), my friends and I looked up Fortnite skins on websites to see what was in the item shop that day. Think of the Fortntie item shop or those websites as a library where you can find all sorts of books, and you can look up a specific genre or book on the library's computer. That is what I am recreating with my class project. Okay, but who is this for? And what does it solve?

It is for those who are curious, so not just for those who love the game Fortnite, that they can't stop playing it. It will also decipher curiosity and confusion. If the user wants to know which skins are in the item shop on that day, they can use my program, and they will know: See? Like my library computer analogy. But what will it encompass?

Items in the item shop include Fortnite outfits (skins), emotes, cars, music, pickaxes, backblings, wraps, shoes, musical instruments, and my information center will encompass said products. It will ask the user to choose which area they want to know first. For example, if they pick skin, the program will print out the names of the different skins that are out in the item shop that day. The user can even ask if a skin that has already been released but is not in the item shop that day will make a return—this will make a prediction system based on how many times the skin has returned. Essentially, my program will incorporate most of what we learned, so classes, object-oriented programming, .txt files, functions, etc.

If you wish to look at each file that supported my envisionary, I included them in this repository. It ain't no high end Video Game user-interface, but this is a beginner's class.
